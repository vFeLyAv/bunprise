# UI-кит Bunprise (`src/ui`)

Компоненты пилота по `docs/spec/design-system-motion.md` §3. Импорт только из барреля: `import { Button, Sheet } from '../ui'`.

Правила, которые кит соблюдает и ждёт от тебя:

- **Основной вид** (с 20.10.2026, решение Кирилла — `docs/decisions/2026-10-20-design-direction-glass.md`): цвета A «Бумага», формы и **видимое стекло** B «Стекло», системный шрифт без засечек. Все значения — в `src/styles/tokens.css` (плюс три маленьких файла, которые грузятся вместе со своим экраном: `scene.css` — сцена старта, `tiles.css` — подложки плиток и аватаров, `mascot.css` — размер маскота).
- **Цвета только через токены**: в компонентах нет ни одного hex. Tailwind-утилиты: `bg-bg`, `bg-surface`, `bg-fill`, `text-text`, `text-text-2`, `text-accent-text`, `bg-accent`, `bg-switch-on`, `bg-scrim`, `text-danger`, `bg-ok-bg` и т. д.; радиусы `rounded-xs|sm|md|lg|xl|full` и формы компонентов `rounded-button` (все текстовые кнопки), `rounded-control` / `rounded-control-inner` (Segmented, чипы, метки; ползунок концентричен), `rounded-hero`, `rounded-sheet`, `rounded-toast`; тени `elev-1|2|3`; типографика `t-display … t-caption-2` (шрифт, вес и трекинг больших заголовков — токены; заголовки переносятся «сбалансированно», поэтому перед « – » в тексте заголовка нужен неразрывный пробел ` `); безопасные зоны `pt-safe`, `pb-safe`, `px-safe`; hit-target `hit`, `hit-expand`.
- **Тема** (например, «Пастель» позже) — это ОДИН файл с переопределением токенов на своём селекторе (`:root[data-palette="pastel"] { … }`): цвета, четыре оттенка стекла, плитки, сцена, при желании формы. Так устроены dev-направления `src/dev/directions/*.css`.
- **Текста в компонентах нет.** Все надписи (`label`, `closeLabel`, `confirmLabel` …) приходят из `t()` — ключи в `src/locales`.
- **Три пружины** (`springs.snappy | smooth | bouncy` из `ui/motion.ts`), анимируем только transform/opacity/цвет. Reduce motion = системная настройка или `<html data-motion="reduce">`: хук `useReducedMotionPref()`, `useSpring('snappy')` сам отдаёт мгновенный переход.
- **Стекло** — по классу на материал (размытие + насыщенность + светлая кромка): `.glass-bar` (TopBar: наверху страницы прозрачная, материал проявляется за `--dur-s`, как только под панель заехал контент — `data-scrolled`), `.glass-sheet` (Sheet: парит в 8 px от краёв, углы 40 px, светлая кромка сверху, под ним затемнение `--scrim`), `.glass-float` + `.glass-accent` (кнопка «+»; `variant="glass"` у `Button`/`IconButton` — маленькие стеклянные кнопки), `.glass-toast` (тост-капсула). Только на панелях, окнах, маленьких плавающих кнопках и тостах — никогда не слой размытия под длинным списком. При «Понизить прозрачность», `data-transparency="reduce"` и без поддержки `backdrop-filter` всё сплошное (переключатели `--solid*` в `tokens.css`, тема их не перебьёт).
- **Плитки подарков и аватары** окрашиваются по стабильному хешу id: `tileTone(id)` → `data-tile` + класс `tile` (у аватара — проп `seed` = id человека). Один и тот же человек или желание везде одного цвета; от броней цвет не зависит.
- **Экраны-сцены** (старт и онбординг) — `Scene` (импорт по файлу `ui/Scene`, не из барреля): тёплый мягко-цветной фон за стеклом. Вместе с ним приходит `styles/scene.css`: `.scene-stage` (свободная высота для кроликов), `.scene-card` (стеклянная карточка, пристыкованная снизу: материал окна, верхние углы `--r-sheet`; кролики выглядывают из-за её верхнего края), `.scene-bleed` (на всю ширину экрана) и продолжение стекла в подвале с юридическими ссылками после `main.scene-page` — карточка и подвал выглядят одним окном. Страница: `<Page flush className="scene-page">`. Сами кролики — `features/mascot-ui/WelcomeBunnies.tsx` (ленивый чанк, см. `docs/contract.md` §12.3).
- **Ссылки-кнопки** роутера (`<Link className={buttonClass(…)}>`) нажимаются как кнопки, если это `PressLink` из `features/shell/MotionLink.tsx` (scale .97 + хаптика) — так сделаны все такие ссылки.
- **Иконки**: каждый `make()` помечен `@__PURE__`; `IconGlobe` и `IconLink` лежат в своих файлах (`iconGlobe.tsx`, `iconLink.tsx`) — оболочка и `/i` импортируют их напрямую, большой модуль иконок в первую загрузку не попадает.
- **Хаптика** — `haptic('tap' | 'select' | 'success' | 'warning' | 'error')` из `ui/haptics.ts`: сама находит `src/lib/haptics.ts` (экспорт `haptic(kind)`, там же звук и настройки), иначе no-op; можно подключить явно `setHaptics(fn)`.
- **Тесты компонентов** в jsdom: первой строкой `import '../ui/test-shims-dom'` (matchMedia + IntersectionObserver). WAAPI-заглушку (`features/mascot-ui/test-shims.ts`) подключай только для сцен маскота — с ней анимации motion не завершаются.
- **Оверлеи** (Sheet, Toast) рендерятся в «слой» — `document.body` или элемент из `LayerRootProvider` (так PhoneFrame держит их внутри телефона).

## Волна 1 (20.10.2026): «тёплое стекло на бумаге» — что нового в ките

- **Сцена за каждым экраном**: `--page-backdrop` (tokens.css) — бумага + четыре мягких цветовых пятна (абрикос, персик-роза, мёд, холодная сирень); один фиксированный слой (`body::before`, без blur). Тонкое бумажное зерно (≤ 4 %, SVG-шум) приходит с китом (`styles/kit.css`). Экраны повода красят сцену цветом повода: `<AmbientTint tone={tileTone(id)} />` (импорт **по файлу** `ui/AmbientTint`; CSS `styles/tint.css` + `styles/tints.css` с `--tint-1…4`).
- **Две семьи материалов.** (а) *Матовые панели* без blur (можно под прокручиваемым списком): `.glass-panel` — все `Card`, группы, герой; `.glass-field` — поля ввода (`FieldShell`: фокус = акцентная кромка, ошибка = `data-invalid`). Живут в `styles/kit.css` (едут с китом, не с `/i`). (б) *Парящее стекло* с настоящим blur — только плавающий хром: `.glass-bar`, `.glass-sheet`, `.glass-float` (+ `.glass-accent`), `.glass-toast` — в `styles/glass.css` (его импортируют TopBar, Sheet, Toast, Button, IconButton и баррель). Классы не переименованы. При «Понизить прозрачность» всё сплошное (`--solid*`, для панелей `--solid-panel`).
- **TopBar**: «Zurück» — стеклянная капсула с шевроном; всё из `right` стоит на ОДНОЙ стеклянной капсуле (как в iOS 26) — передавай обычные `IconButton variant="plain"` / ghost-кнопки, не стеклянные. Материал самой панели по-прежнему проявляется после прокрутки.
- **Sheet следует за пальцем**: тянуть вниз можно не только за ручку, но и за содержимое, когда оно прокручено до верха (браузерная прокрутка этого касания отменяется); отпускание учитывает скорость (смещение + 200 мс скорости > 35 % высоты или бросок > 500 px/с → закрыть, иначе пружина назад), вверх — резинка; при пересечении порога — лёгкая хаптика.
- **Новые части**: `Checkbox` (настоящий checkbox на матовом квадратике, галочка с пружиной bouncy), `OtpField` (одно поле one-time-code поверх шести матовых ячеек, мигающий курсор), `DateBadge` (календарный листок цветом повода: месяц · число · день), `IconTile` (цветной квадратик-иконка строки настроек, оттенки `--icon-*` в `styles/icontile.css`). `Segmented`: у варианта может быть `tone: 'ok' | 'accent' | 'neutral'` (цвет ползунка), выбранная иконка «подпрыгивает». `Switch`: `leading` (иконка строки). `Avatar`: размер 24 и `ring` (для стопки лиц). Иконки: `IconSparkle`, `IconBunny`, `IconBattery`, `IconQuestion`. Радиус отдельной карточки — `rounded-card` (`--r-card`, 28 px).
- **Уровень движения** (K9): `<html data-motion="full|reduce|off" data-bunnies="on|off">` пишет `src/motion/level.ts` (настройка × системная × батарея). `useReducedMotionPref()` = true при reduce и off; при `off` все длительности 0 и `motion` мгновенный (нажатие всё равно сразу меняет цвет). React: `useMotionLevel()` / `useMotionState()` (`src/motion/useMotionLevel.ts`), без стора — `useMotionAttr()` / `useBunniesShown()` (`ui/motionMode.ts`). Блок настроек: `<MotionSettingsSection />` (`src/motion/MotionSettingsSection.tsx`, неймспейс `motion`).

## Motion (`ui/motion.ts`)

`springs` (snappy / smooth / bouncy — значения живут в `src/motion/springs.ts`, кит их реэкспортирует), `instant`, `fade`, `springCss` (для CSS `transition`), `useReducedMotionPref()`, `useMotionMode()`, `useSpring(name)`, `useTapScale(scale)`.

В CSS пользуйся токенами: `transition: transform var(--dur-snappy) var(--ease-snappy)` или Tailwind `duration-(--dur-s) ease-(--ease-out)` — при reduce motion токены сами обнуляют длительности пружин.

## Чего пока нет (после каркаса)
