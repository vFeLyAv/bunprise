# Authentication provider artwork

Retrieved from the providers' official resources on 2026-10-19. Assets are served locally; these buttons do not load provider scripts, fonts, or remote images.

- `google-g.svg`: unchanged G paths/colors from the HTML button configurator linked by [Google's sign-in branding guidelines](https://developers.google.com/identity/branding-guidelines#render-html-button-element). The white button uses the standard colored G, not a monochrome substitute. Google also provides its [approved asset download](https://developers.google.com/static/identity/images/signin-assets.zip).
- `apple-white.svg`: `Logo - SIWA - Left-aligned - White - Medium.svg` from [Apple Design Resources](https://developer.apple.com/design/resources/#technologies), [original download](https://devimages-cdn.apple.com/design/resources/download/Logo-Sign-in-with-Apple.dmg). The black background rectangle was omitted to make the artwork transparent on the black button. The official white logo path, viewBox, aspect ratio, and built-in padding remain unchanged. The complete 44px-high artboard scales to the button's 52px height; the logo is not cropped. See [Apple's button guidance](https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple) and the included Apple Design Resources License. Not used since 2026-10-20 (kept for a dark theme).
- `apple-black.svg` (2026-10-20, design pass): the black logo for Apple's **"white with outline"** button style (HIG: for white or light backgrounds — the app uses it everywhere now, blocker 14 in `docs/design/directions.md`). Made from `apple-white.svg` by changing only the fill to `#000000` — the same logo path, viewBox, aspect ratio and built-in padding as the white file. The same download also contains `Logo - SIWA - Left-aligned - Black - Medium.svg`; before the public launch, compare the path with that official black file (or replace this file with it).

Button height, pill radius, system font, translated action labels, focus feedback, and disabled/loading behavior follow the existing Bunprise UI kit. Provider colors and artwork are shared between the method selector and actual OAuth action.
