# Архив юридических черновиков пилота

Источник: `docs/spec/legal-pilot.md` §4 и принятые исправления `docs/spec/pilot-decisions.md` §0 / `docs/reviews/2026-10-19-codex-legal.md` (L1–L20). Нового юридического заключения нет. Английские версии передают те же положения; отсутствующие имя, адрес, контакты, даты, договоры и операционные сроки остались плейсхолдерами. Тексты сохраняют явную пометку черновика.

Формат: `<kind>.<version>.<locale>.md`, где `kind` = `terms`, `privacy_notice`, `age_18plus`; версии совпадают с `lib/legal.ts` и серверными `legal_versions`. `impressum.pilot-draft.<locale>.md` не является записью принятия условий. До реального пилота оператор должен заполнить и проверить плейсхолдеры, сроки, договоры и настройки. Подтверждение заключённого DPA и работающего резервного копирования не выдумано.

`features/legal/archive.ts`: `hasLegalText(kind, version, locale)` проверяет точное наличие; `loadLegalText(...)` возвращает точный исходный Markdown или `null`. Профиль должен проверить серверную версию и выбранный язык перед записью. Нет подстановки другой версии или немецкого текста вместо отсутствующего перевода. `?version=...&lang=de|en` на юридической странице выбирает тот же архив. Markdown рендерится безопасно как текст/элементы React, без HTML.

Когда эти версии станут показываться пользователям, не менять их содержимое: новая редакция требует новых файлов, обновления серверной версии миграцией и зеркала `LEGAL_VERSIONS`. Активация Google, Turnstile, превью ссылок или иных описанных как отключённые функций требует проверки текста и новой версии до включения. Текущий черновик не утверждает юридическую готовность к запуску.
